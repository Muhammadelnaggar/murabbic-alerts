## ما تم إصلاحه في المرشحات المحلية

1. تأمين الداش: منع تداخل GET وأزرار القرار، وإسقاط رد GET قبل POST، ومراعاة إخفاء الصفحة مع إبقاء مؤقت الدقيقة.
2. إغلاق سباق جديد اكتُشف في مراجعة هذه الجولة: عند رجوع الداش وهو ينتظر طلب GET قديم، يُرفض أثر رد ذلك الطلب وتُجدول قراءة واحدة جديدة فور اكتماله، حتى لا تنتظر واجهة المزرعة موعد الدقيقة التالية.

## محاذير التنفيذ

- **لا يوجد Commit أو Push أو Deploy**. **لم يختبر Render الحقيقي**.
- هذا لا يحل بعد بطء GET الثقيل ولا يثبت الجاهزية لـ1000 مستخدم.
- لا يُلغى تحديث الدقيقة أو استعادة تاريخ BVD حتى بناء نتائج جاهزة وتغطية مسارات الكتابة والاستحقاق.
- مرشح Stage2 يُسرّع طريق الانتقال لكنه يختلف في نطاق أرشفة التنبيهات عند POST الخاص بالتنقل؛ يحتاج اعتمادًا وظيفيًا قبل النشر.
- لا تعتبر الاختبارات المحاكية إثباتًا لسرعة Live.
